# Psst platform

The platform behind [Psst](https://psst.zigao.wang): the database, the curation pipeline, the task workflows, the admin console, and the public website. It replaces the [psst-content](https://github.com/ZigaoWang/psst-content) system.

The code is public so it can be read. The content (places, stories, guide information, photos, and the research behind them) lives in the Psst database and is never stored in this repository. Neither the code nor the content is licensed for reuse; see [LICENSE](LICENSE).

- [docs/plan.md](docs/plan.md): why the platform is being rebuilt, and the approach.
- [docs/design.md](docs/design.md): the specification.
